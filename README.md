# coderabbit-approvals-demo

A tiny shop API used in the **AI-Driven Programming** course to show how CodeRabbit
rates the merge risk of a pull request and approves only the safe ones.

```bash
npm install
npm test
npm run dev   # http://localhost:3000
```

Demo users (Bearer tokens): `token-alice`, `token-bob` (customers), `token-admin` (admin).
